StackForge Studio

Generer une application complete depuis une base de donnees

StackForge transforme une structure MySQL ou PostgreSQL en backend Node.js, API CRUD, frontend Angular/Ionic, documentation et archive livrable.

Comment l'utiliser

Exemple concret

1
Connecter la base

Choisir MySQL ou PostgreSQL, puis entrer host, port, utilisateur, mot de passe et nom de base.

2
Lancer la generation

StackForge lit les tables, colonnes, types, cle primaire et cree les ecrans CRUD.

3
Tester la demo

Dans le projet genere, ouvrir /login avec dieng.tech et dieng123.

4
Continuer le developpement

Le backend expose les endpoints GET, POST, PUT, DELETE et le frontend contient les pages Angular/Ionic.
