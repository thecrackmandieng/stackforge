# Brief video IA - StackForge Studio

Createur: Moustapha Dieng

## Objectif

Creer une video courte, moderne et professionnelle qui explique pourquoi StackForge Studio est important, comment l'utiliser, et ce qu'il genere automatiquement.

Format recommande:
- Duree: 75 a 90 secondes
- Ratio: 16:9 pour YouTube et presentation
- Style: SaaS moderne, interface claire, animations de diagrammes, plans d'ecrans produit
- Ton: confiant, pedagogique, accessible
- Langue voix off: francais

## Prompt IA video principal

Generer une video professionnelle de presentation SaaS pour "StackForge Studio", cree par Moustapha Dieng. Montrer une interface moderne de generateur full-stack. La video explique qu'a partir d'une base de donnees MySQL ou PostgreSQL, l'outil genere automatiquement un backend Node.js avec API CRUD, un frontend Angular/Ionic moderne, une documentation backend, une page de connexion demo et une archive zip. Utiliser des animations de diagrammes propres: Base de donnees -> Analyse du schema -> Backend Node.js -> Frontend Ionic -> Documentation -> Projet telechargeable. Style visuel: tableau de bord professionnel, couleurs bleu, vert profond, blanc, gris clair, cartes d'interface propres, transitions fluides, typographie moderne. Inclure des exemples de tables users, products, categories. Montrer un login demo avec identifiants dieng.tech et dieng123. Terminer avec le texte: "StackForge Studio - Cree par Moustapha Dieng".
